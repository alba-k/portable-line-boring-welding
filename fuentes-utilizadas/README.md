# Fuentes utilizadas

Fuentes citadas en el informe *Mandriladora portátil y sistema de recargue*, reunidas en un solo lugar. Cada PDF lleva como prefijo el número de la sección en cuyo `referencias.bib` está la fuente (01, 02 o 07). La lista se generó a partir de los `\cite{}` de los `.txt`: si se agrega o quita una cita, hay que actualizarla.

Total: 50 fuentes citadas.

**Para completar la carpeta:** ejecutar `descargar-fuentes.ps1` (clic derecho > Ejecutar con PowerShell). Descarga los PDF libres, guarda cada página web como PDF con Chrome o Edge y deja en `enlaces/` un acceso directo `.url` a cada fuente, incluidos los videos y las obras de pago.
